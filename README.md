# proxy4you

Клиент подписок на основе Hiddify 5.5.5 для macOS Apple Silicon и Android.

В публичном выпуске 5.0.0 пока доступна только версия для Android. Сборка macOS не публикуется.

## Скачать

- [Страница загрузки](https://lynatick.github.io/proxy4you/)
- [Последний выпуск](https://github.com/Lynatick/proxy4you/releases/latest)
- [Конфигурации и подписки](https://lynatick.github.io/goida/)

## Требования

- macOS 27 или новее, Mac с Apple Silicon;
- Android 8.0 (API 26) или новее, включая Android TV.

## Возможности

- отдельные подписки и упорядоченные списки подписок;
- автоматический переход к следующей подписке в списке, если все конфигурации текущей недоступны;
- загрузка в ядро только выбранной подписки;
- обновление списка подписок вместе с входящими в него подписками;
- управление системным прокси macOS с запросом пароля;
- навигация с пульта и адаптированный интерфейс Android TV;
- проверка новой версии приложения и переход на страницу загрузки;
- русскоязычный интерфейс.

Версия приложения начинается с 5.0.0. Исходный проект Hiddify и условия его лицензирования сохранены в репозитории.
